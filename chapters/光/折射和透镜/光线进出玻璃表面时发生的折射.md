# 光的折射实验数据记录（玻璃）

本数据基于光从空气（折射率 n₁ ≈ 1.00）射入玻璃（折射率 n₂ ≈ 1.50）的折射实验，依据斯涅耳定律（Snell's Law）：sinθ₁ / sinθ₂ = n₂ / n₁ = 1.50。表格中记录了入射角 θ₁ 从 0° 到 85°（步长 5°）共 18 组数据，包括对应的出射角 θ₂、正弦值以及比值。

> - 比值稳定在 1.50，与玻璃折射率一致，验证了斯涅耳定律。
